## 🔥 主作品：拾域 CRM（shiyu-crm）

一套为**私域运作模式**量身打造的**客户全生命周期管理系统**——从线索获客、客户转化、订单成交到售后回款，业务闭环一站打通。

**🎯 天然契合多渠道获客 + 私域承接 + 微信成交的打法：**

`信息流广告` · `CID 模式` · `直播间订单` · `电商订单` · `电话销售`

——不管客户从哪来，统一进线索池、分配即建档、加微跟进、成交复购全流程留痕，**拿来即用**。

### 🚀 在线体验

> **体验地址：<http://47.253.98.210>** （生产环境实时运行）
>
> 打开登录页 → 点「注册账号」→ 注册成功即可进入系统。
> 为防止滥用，新账号需管理员授权后解锁完整功能；浏览器如提示"不安全"，是因为站点暂未配置 HTTPS 证书，属正常现象。

**这不是玩具项目：**

- 🧩 **25 个业务模块 / 276 个接口**：客户 / 订单 / 线索 / 佣金 / BI 报表 / IM 即时通讯 / 售后工单 / 财务回款……接口文档全部由代码自动生成并强制一致性校验
- 🛡️ **企业级权限与安全**：角色层级数据范围引擎 + 字段级权限 + AES-256-GCM 字段加密 + 全链路审计日志 + 全局水印 + 登录防爆破
- 🤖 **AI 深度落地**：AI 销售助手（客户画像 / 风险预警 / 话术推荐）、线索价值预测、Agent 规则引擎（定时扫描 + 自动提醒）
- 💰 **私域生意内核**：线索身份证同号归因、收款双通道、佣金自动冲回、业绩归属铁律——都是私域团队真金白银踩出来的规则
- ⚙️ **大厂级工程化**：SemVer 自动发版（推 tag 自动出 Release）、每日自动备份、压测验证（50 并发 P95 1.4s）
