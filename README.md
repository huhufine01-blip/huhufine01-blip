## 🔥 正在打造：[拾域 CRM](https://github.com/huhufine01-blip/shiyu-crm)

一套**客户全生命周期管理系统**——从线索获客、客户转化、订单成交到售后回款，业务闭环一站打通。

**这不是玩具项目：**

- 🧩 **20+ 业务模块**：客户 / 订单 / 线索 / 佣金 / BI 报表 / IM 即时通讯 / 售后工单 / 财务回款……
- 🛡️ **企业级权限引擎**：角色层级数据范围 + 字段级权限 + 全链路审计日志 + 全局水印
- 🤖 **AI 深度落地**：AI 销售助手（客户画像 / 风险预警 / 话术推荐）、Agent 规则引擎（定时扫描 + 自动提醒）
- ⚙️ **大厂级工程化**：SemVer 发版自动化、每日自动备份、压测验证（50 并发 P95 1.4s）
